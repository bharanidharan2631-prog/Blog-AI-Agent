# Blog AI Agent

A Streamlit-based AI Blog Agent that retrieves blog information from a SQLite database and answers user questions using OpenRouter LLM.

## Features

* View blogs from database
* Search blog topics
* Ask questions about blogs
* AI-powered answers using OpenRouter
* Streamlit web interface

## Technologies Used

* Python
* Streamlit
* SQLite
* OpenRouter API
* OpenAI SDK

## Project Structure

```text
Blog-AI-Agent/
│
├── database/
│   └── blogs.db
├── main.py
├── README.md
├── .gitignore
└── .env
```

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Streamlit:

```bash
streamlit run main.py
```
